# Finboard — финансовый результат продаж на маркетплейсах

Streamlit-дашборд: прибыль по каждому маркетплейсу (Wildberries, Ozon) и вместе, по кабинетам,
месяцам и товарам. Данные приходят по API кабинетов, ключи вводятся в интерфейсе.

## Как считается

- **Деньги — из отчётов маркетплейса, без пересчёта.** Ozon: начисления (`/v1/finance/accrual/by-day`),
  сходятся с «Отчётом по начислениям» до копейки. WB: детализация отчётов реализации
  (`finance-api /api/finance/v1/sales-reports/detailed`), отчёты по России и СНГ.
- **Выручка — по цене продавца**: Ozon = Выручка + Баллы за скидки + Программы партнёров; WB = цена со
  скидкой продавца (СПП платит WB). Комиссия включает эквайринг.
- **Реклама.** Ozon: сумма из начислений; клики раскладываются по товарам по статистике кампаний,
  «оплата за заказ: выбранные товары» — по отчёту о заказах; «все товары» остаётся общим расходом.
  WB: расход из кабинета продвижения (удержания за рекламу в отчёте не дублируются).
- **Три базы** на странице «Товары»: выкупы, заказы, сделки (выкупы + возвраты + отмены).
- **Себестоимость** с датой начала действия, общая или для кабинета.
- **Налоги** по юрлицу, нарастающим итогом с января: УСН 6/15 %, ОСНО (ООО, ИП), АУСН 8/20 %;
  НДС на УСН автоматически по порогам 2026 года (освобождение до 20 млн, затем 5 % / 7 %) или вручную.
- **Постоянные расходы** вводятся вручную по месяцам; за неполный месяц — пропорционально дням.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # задать APP_SECRET (и OWNER_PASSWORD на сервере)
streamlit run dashboard/app.py
```

Переменные окружения — в `.env.example`. На relaxdev: `DATABASE_URL` на PostgreSQL проекта
(без `sslmode`/`ssl`/`channel_binding`), `APP_SECRET`, `OWNER_PASSWORD`. Данные обновляются в процессе
дашборда каждый день в `SYNC_HOUR` (06:00 МСК), последние 14 дней перечитываются.
Ручная загрузка: `python scheduler.py [cabinet_id YYYY-MM-DD YYYY-MM-DD]`.

## Доступ

Владелец входит по паролю. Ссылка `?share=<токен>` (страница «Доступ по ссылке») открывает отчёты
только на чтение, с выбором кабинетов и скрытием себестоимости; ссылку можно отозвать.

## Структура

```
core/        настройки, база, модели, шифрование ключей
sources/     клиенты Ozon Seller/Performance API и WB API
pnl/         начисления -> журнал, расчёт ОПиУ, налоги
sync/        загрузка данных по кабинетам
dashboard/   страницы Streamlit
tests/       тесты; эталонные данные продавцов — в tests/private (не в репозитории)
```

```bash
python -m pytest -q tests
```
